# 🛡️ 서명 잠깐만

> **"서명하기 전에, 이 계약서가 법을 지키는지 30초 안에 확인한다"**  
> RAG 기반 근로계약서 법률 자문 지원 챗봇

---

## 📌 1. 프로젝트 개요

근로자가 근로계약서에 서명하기 전이나 근무 중 의문이 생겼을 때, 계약서 조항이 **근로기준법 등 최신 노동관계법을 준수하는지 근거 조문과 함께 안내**하는 AI 자문 보조 서비스입니다.

- **팀명**: 일조 머스크 (1JO Musk)
- **주요 산출물**: 
  - `app.py`: Gradio 기반 대화형 웹 애플리케이션
  - `eval/`: 30개 검증 데이터셋 기반 정량 평가 리포트
  - `docs/sources.md`: 인용 법령 및 판례 출처 메타데이터
- **핵심 목표**: 법률 사각지대에 놓이기 쉬운 아르바이트, 사회초년생, 계약직, 시니어 일용직 근로자가 불리하거나 위법한 계약 조항을 스스로 식별할 수 있도록 지원합니다.

---

## 🚨 2. 해결하고자 하는 문제 

근로계약서 작성 시 근로시간, 임금, 휴가, 해고 조항 등의 적법성을 일반인이 직접 검증하기는 어렵습니다.
- **노무사 상담의 장벽**: 비용과 시간 소요
- **법률 용어의 난해함**: 조문 및 판례 이해의 어려움
- **위법 조항의 무단 체결**: 포괄임금 남용, 주휴수당 누락, 최저임금 미달, 연차 미기재 상태 방치

### 👥 대상 사용자 및 활용 시나리오
| 대상 | 상황 | 활용 방식 |
| :--- | :--- | :--- |
| **아르바이트 / 단시간** | 주 15시간 미만/이상 근무 시 | 주휴수당 미지급 조항의 위법 여부 및 근거 조문 확인 |
| **계약직 / 사회초년생** | 계약 체결 및 갱신 직전 | 필수 기재사항(임금·근로시간·휴일 등) 누락 및 독소조항 점검 |
| **중장년 / 일용직 근로자** | 임금 계산 및 퇴직금 의문 시 | 쉬운 일상어로 질의 시 최저임금법·퇴직급여법 기준 설명 및 노동부(1350) 연결 안내 |

## 📚 3. 지식베이스 구축

국가법령정보센터 기준 현행 법령 및 중요 판례(PDF 12건)를 기반으로 신뢰성 높은 RAG 지식베이스를 구성합니다.  
*(※ 원본 PDF는 저장소에 보관하지 않으며, 공포번호·시행일 등이 명시된 출처를 `docs/sources.md`에 기록 관리합니다.)*

- **핵심 법령**: 근로기준법(시행령·시행규칙 포함), 최저임금법(시행규칙 포함), 기간제 및 단시간근로자 보호 등에 관한 법률, 근로자퇴직급여 보장법
- **관련 법령**: 근로자참여 및 협력증진에 관한 법률, 대학교원 기간임용제 탈락자 구제를 위한 특별법, 민법(고용계약 일반), 상법(임원 경계 사례)
- **판례/해석**: 노동법 중요판례 평석(법 조문만으로 판단이 어려운 경계 사례 해석 근거)

## 🎯 5. 목표 성능 지표

평가 질문셋 30개를 기준으로 아래 정량 지표를 달성하는 것을 목표로 합니다.

| 지표 (Metric) | 목표치 (v2) | 측정 기준 |
| :--- | :---: | :--- |
| **정답률** | **$\ge$ 80%** | QA 질문셋 기준 사실관계 부합 여부 (O/X) |
| **근거 일치율** | **$\ge$ 90%** | 인용된 법 조문이 실제 판단 근거와 일치하는 비율 |
| **Hallucination 방지 (모름 처리)** | **100%** | 지식베이스에 근거가 없는 질의에 대해 "확인 불가" 응답률 |
| **응답 지연 시간** | **$\le$ 10초** | 1회 질의당 평균 생성 소요 시간 |

## ⚠️ 6. 면책 조항 및 보안 정책

1. **법적 효력 고지**:
   - 본 서비스는 **법률 대리나 정식 소송 자문이 아닌 단순 정보 제공용 참고 서비스**입니다.
   - 모든 답변 하단에 공식 노무 상담 창구(`고용노동부 고객상담센터 ☎1350`) 안내 문구를 필수 표기합니다.
2. **개인정보 보호**:
   - 업로드된 계약서 문서는 서버에 영구 저장되지 않으며, 분석 세션 종료 즉시 메모리에서 폐기됩니다.
3. **보안 관리**:
   - LLM API 키는 Hugging Face Spaces Secrets / 환경 변수로 관리하며, `.gitignore`를 통해 코드 저장소 노출을 방지합니다.
