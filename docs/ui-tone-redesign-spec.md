# UI 톤앤매너 개편 스펙 — "판사봉 캐릭터" 테마

> 상태: **구현 완료** · 범위: 색·글자·여백·모서리·그림자 등 **느낌만** 바꿉니다.
> 화면 구조(헤더 → 면책 고지 → 탭 3개)와 컴포넌트 key 목록은 그대로 둡니다. → `docs/ui-layout-rules.md` 4번 표 변경 없음

## 1. 왜 바꾸나

| 지금 | 문제 | 바꾼 뒤 |
| --- | --- | --- |
| 남색 잉크 + 노란 형광펜 | 형광펜 노랑이 튀어서 "검토 중"인 긴장감, 차가운 인상 | 캐릭터에서 뽑은 **따뜻한 무채색 + 버건디 하나** |
| 차가운 slate 회색(`#F7F8FA`, `#DDE1E8`) | 캐릭터(갈색·크림·버건디)와 온도가 안 맞음 | 살짝 따뜻한 회색(웜 그레이) |
| 형광펜 밑줄 제목 | 장식이 많아 보임 | 굵기·크기만으로 강조, 장식 제거 |

목표 키워드: **깔끔함 · 신뢰감 · 친근함**. 법률 서비스라 믿음직해야 하지만, 캐릭터가 귀여우니 딱딱하지 않게.

## 2. 캐릭터에서 뽑은 색

| 캐릭터 부위 | 대략 색 | UI에서 쓰는 곳 |
| --- | --- | --- |
| 법복 (검정) | `#2B2523` 따뜻한 차콜 | 본문 글자 |
| 법복 안감 (버건디) | `#7A2E3A` | **포인트 색 단 하나** — 주 버튼, 선택된 탭 밑줄, 포커스 |
| 법전 금박·저울 (골드) | `#C9974A` | 아주 작은 포인트(배지 등)에만. 글자색으로 쓰지 않음 |
| 판사봉 손잡이 (꿀색) | `#F6E3B8` | 추천 질문 hover 배경 (기존 노란 형광펜 대체) |

| 볼터치 (코랄) | — | UI에는 쓰지 않음 (캐릭터 안에서만) |

원칙: **넓은 면은 무채색, 색은 버건디 하나만.** 골드·꿀색은 보조로 아주 조금. 캐릭터가 이미 색이 많아서 UI가 조용해야 캐릭터가 살아납니다.

## 8. 캐릭터 — 항상 보이고, 답변 준비 중에만 움직이며 말함

**목표:** 질문하기 탭 맨 위(탭 바로 아래, 채팅창 위)에 캐릭터와 말풍선이 **항상 떠 있습니다.**

| 상태 | 캐릭터 | 말풍선 |
| --- | --- | --- |
| 평소 | 1번 컷(판사봉을 낮게 든 자세)으로 멈춤 | `JUDGE_IDLE` = "궁금한 노동법, 저에게 물어보세요!" |
| 답변 준비 중 | 판사봉 두드리기 애니메이션 | `JUDGE_BUSY` = "법전을 찾아보고 있어요…" |
| 답변이 나오기 시작 | 다시 멈춤 | 다시 `JUDGE_IDLE` |

컷 넘기기는 CSS `steps()` 애니메이션, "지금 로딩 중인지" 판단은 CSS `:has()`로 하므로 **JS도, 새 컴포넌트 key도 필요 없습니다.**

### 화면 배치

```
[질문하기] [자주 묻는 질문] [법령 요약]
┌──────┐  ╭───────────────────────────────╮
│캐릭터 │ ◀ 궁금한 노동법, 저에게 물어보세요! │   ← #judge-row (gr.HTML 하나)
│72×96 │  ╰───────────────────────────────╯
└──────┘
┌─────────────────────────────────────────┐
│ 채팅창 (#chatbot)                          │
└─────────────────────────────────────────┘
 추천 질문 · 입력창 · 대화 지우기 (그대로)
```

- 캐릭터 왼쪽, 말풍선 오른쪽. 말풍선 꼬리는 캐릭터 쪽을 향합니다.
- 말풍선: 배경 `SURFACE`, 테두리 `RULE`, 모서리 12px, 글자 `INK` 0.95rem. 바쁠 때도 색은 그대로 두고 문구만 바꿉니다 (깔끔함 유지).
- 캐릭터는 세로로 긴 몸이라 **72×96px**(3 : 4)로 표시합니다. 캐릭터+말풍선 줄이 세로 공간을 쓰므로 채팅창 높이를 440px → 380px으로 줄여 전체 높이를 비슷하게 유지합니다.
- 모바일(768px 이하): 캐릭터 54×72px, 말풍선 글자 0.88rem. 가로 배치는 유지합니다.
- 캐릭터는 꾸밈 그림이므로 `role="img"` + `aria-label="판사 캐릭터"`, 말풍선은 `aria-live="polite"`로 두어 화면 낭독기에도 상태가 전달되게 합니다.

### 동작 원리

1. A가 질문하기 탭 맨 위에 꾸밈용 `gr.HTML`을 하나 그립니다. 이벤트를 걸 일이 없으니 `build_layout()` dict에 넣지 않습니다 → key 목록 변경 없음.
2. 말풍선 안에는 `JUDGE_IDLE`, `JUDGE_BUSY` 문구를 **둘 다** 넣어두고 CSS로 하나만 보입니다. 문구는 `ui/content.py`에 둡니다 (문구는 content.py 규칙 유지).
3. B의 로딩 문구 `LOADING_TEXT`에 **보이지 않는 표식** `<span class="judge-busy"></span>`을 넣습니다.
4. CSS가 "채팅창 안에 표식이 있으면 캐릭터를 움직이고 말풍선을 바쁜 문구로 바꿔라"라고 정합니다.
5. 답변 첫 조각·오류·빈 답변 등 **모든 경우에** `on_ask()`가 로딩 메시지를 덮어쓰므로(`ui/chat_actions.py`의 `history[-1] = ...`) 표식이 사라지고 캐릭터·말풍선은 자동으로 평소 상태로 돌아옵니다.

```html
<!-- ui/layout.py가 그리는 HTML (문구는 content.py에서) -->
<div id="judge-row">
  <div id="judge" role="img" aria-label="판사 캐릭터"></div>
  <p id="judge-bubble" aria-live="polite">
    <span class="judge-say-idle">{JUDGE_IDLE}</span>
    <span class="judge-say-busy">{JUDGE_BUSY}</span>
  </p>
</div>
```

```css
/* 평소: 1번 컷에 멈춤, 평소 문구만 보임 */
#judge {
  width: 72px; height: 96px; flex: none;
  background: url("/gradio_api/file=ui/assets/judge-sprite.webp") 0 0 / 600% 100% no-repeat;
}
.judge-say-busy { display: none; }

/* 채팅창에 로딩 표식이 있는 동안: 판사봉 두드리기(6컷 반복) + 바쁜 문구 */
/* steps(6, jump-none): 0%→100% 사이를 6칸으로 나눠 각 컷을 같은 시간씩 보여줌 */
#tab-chat:has(.judge-busy) #judge {
  animation: judge-tap 0.8s steps(6, jump-none) infinite;
}
#tab-chat:has(.judge-busy) .judge-say-idle { display: none; }
#tab-chat:has(.judge-busy) .judge-say-busy { display: inline; }

@keyframes judge-tap { to { background-position: 100% 0; } }
@media (prefers-reduced-motion: reduce) {
  #tab-chat:has(.judge-busy) #judge { animation: none; }  /* 문구 변화는 유지 */
}
```

```python
# ui/chat_actions.py (B 담당, 합의 완료) — 바뀌는 건 이 한 줄뿐
LOADING_TEXT = '<span class="judge-busy"></span>⏳ 답변을 찾는 중...'
```

- 이미지 파일은 `gr.set_static_paths()`로 공개해야 브라우저에서 불러올 수 있습니다 (`app.py`).
- 구현 때 직접 띄워서 확인할 것: Chatbot이 `<span class>`를 지우지 않고 남기는지(HTML 정리 기능), 이미지 경로가 열리는지, `gr.HTML`이 `aria-live`를 남기는지.
- `:has()`는 최신 Chrome·Safari·Firefox 모두 지원합니다.

### 스프라이트 준비 (새로 받은 이미지 기준)

원본: 2172×724, 가로 6컷, 투명 배경 → **그대로 쓸 수 있는 상태.** 다만 아래 정리가 필요합니다.

| 확인한 것 | 수치 | 처리 |
| --- | --- | --- |
| 배경 | 투명 ✅. 위쪽에 보이는 점들은 투명도 1/255짜리라 화면에선 안 보임 | 투명도 16 이하 픽셀은 0으로 지워서 깔끔하게 |
| 컷 간격 | 6등분(362px)이 아님. 실제 컷 폭 348~382px, 5·6번 컷은 서로 붙어 있음 | 6등분으로 자르지 않고, **캐릭터 덩어리 기준으로** 잘라냄 |
| 발 위치 | 발 바닥 높이는 모두 같음(y≈612) ✅. 가로 위치는 6등분 기준 최대 약 30px 차이 | 각 컷을 **발 중심 x**에 맞춰 같은 칸 가운데에 놓음 → 재생할 때 안 떨림 |
| 머리 높이 | 4·5번(내려치는 컷)이 다른 컷보다 약 15px 낮음 | 내려칠 때 몸을 숙이는 자연스러운 동작이라 그대로 둠 |
| 크기 | 캐릭터 한 컷 약 360×480 | 칸 하나를 3 : 4로 맞추고 2배 해상도 **144×192px**로 줄임 → 전체 864×192 WebP (수십 KB) |

**컷 순서 (원본 번호 → 동작)**

| 재생 순서 | 원본 컷 | 동작 |
| --- | --- | --- |
| 1 | 1번 | 봉을 낮게 듦 — **평소 멈춤 자세** |
| 2 | 6번 | 봉을 들어 올리기 시작 |
| 3 | 2번 | 봉을 높이 듦 |
| 4 | 3번 | 가장 높이 듦 |
| 5 | 4번 | 내려치는 중 |
| 6 | 5번 | 쾅! (봉이 맨 아래) → 다시 1로 |

- 이 순서로 다시 붙인 파일을 `ui/assets/judge-sprite.webp`로 저장합니다. 정리 스크립트는 한 번만 돌리면 되므로 저장소에 넣지 않고, 결과 이미지만 커밋합니다.
- 0.8초에 한 바퀴(컷당 약 0.13초). 실제로 띄워 보고 너무 빠르면 1.0초로 조정합니다.
