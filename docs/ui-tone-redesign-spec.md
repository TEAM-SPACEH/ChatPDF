# UI 톤앤매너 개편 스펙 — "판사봉 캐릭터" 테마

> 상태: **구현 완료** · 1차: 색·글자·여백 등 느낌 개편 → 2차: 질문하기 탭 채팅창을 **메신저형**으로 개편 (8번)
> 화면 구조(헤더 → 면책 고지 → 탭 3개)와 컴포넌트 key 목록은 그대로 둡니다. → `docs/ui-layout-rules.md` 4번 표 변경 없음

## 1. 왜 바꾸나

| 지금 | 문제 | 바꾼 뒤 |
| --- | --- | --- |
| 남색 잉크 + 노란 형광펜 | 형광펜 노랑이 튀어서 "검토 중"인 긴장감, 차가운 인상 | 캐릭터에서 뽑은 **따뜻한 무채색 + 버건디 하나** |
| 차가운 slate 회색(`#F7F8FA`, `#DDE1E8`) | 캐릭터(갈색·크림·버건디)와 온도가 안 맞음 | 살짝 따뜻한 회색(웜 그레이) |
| 형광펜 밑줄 제목 | 장식이 많아 보임 | 굵기·크기만으로 강조, 장식 제거 |

목표 키워드: **깔끔함 · 신뢰감 · 친근함**. 법률 서비스라 믿음직해야 하지만, 캐릭터가 귀여우니 딱딱하지 않게.

## 2. 캐릭터에서 뽑은 색

| 캐릭터 부위 | 대략 색 | UI에서 쓰는 곳 |
| --- | --- | --- |
| 법복 (검정) | `#2B2523` 따뜻한 차콜 | 본문 글자 |
| 법복 안감 (버건디) | `#7A2E3A` | **포인트 색 단 하나** — 주 버튼, 선택된 탭 밑줄, 포커스 |
| 법전 금박·저울 (골드) | `#C9974A` | 아주 작은 포인트(배지 등)에만. 글자색으로 쓰지 않음 |
| 판사봉 손잡이 (꿀색) | `#F6E3B8` | 추천 질문 hover 배경 (기존 노란 형광펜 대체) |
| 가발 (크림 화이트) | `#FAF8F5` | 페이지 배경 |
| 볼터치 (코랄) | — | UI에는 쓰지 않음 (캐릭터 안에서만) |

원칙: **넓은 면은 무채색, 색은 버건디 하나만.** 골드·꿀색은 보조로 아주 조금. 캐릭터가 이미 색이 많아서 UI가 조용해야 캐릭터가 살아납니다.

## 8. 질문하기 탭 — 메신저형 채팅 + 판사 캐릭터

**왜:** 1차의 "네모 상자 채팅창 + 위에 고정 캐릭터"는 답답했음. 상자를 없애고, 판사가 **답변할 때마다 직접 말하는** 메신저 형태로 바꿈.

### 화면

```
[질문하기] [자주 묻는 질문]
                                ╭──────────────────────╮
                                │ 주휴수당 받나요?        │  ← 내 질문: 버건디 말풍선(오른쪽)
                                ╰──────────────────────╯
(판사 얼굴) ╭──────────────────────────────╮
            │ 네, 받을 수 있어요. …          │  ← 판사 답변: 흰 말풍선 + 얼굴 아바타(왼쪽)
            │ ▏출처: 근로기준법 제55조 (p.12)  │
            ╰──────────────────────────────╯
  (전신 판사가 봉 두드림) ⏳ 답변을 찾는 중...   ← 답변 준비 중
 추천 질문 알약들
╭─────────────────────────────────────┬────────╮
│ 예) 수습기간에도 …                    │질문하기│  ← 둥근 입력줄 하나
╰─────────────────────────────────────┴────────╯
```

| 상태 | 화면 |
| --- | --- |
| 대화 없음 | 가운데에 말풍선("궁금한 노동법, 저에게 물어보세요!") + 판사 전신(96×128, 3.2초 주기로 살짝 둥실) + 안내 두 줄. `gr.Chatbot(placeholder=...)` HTML |
| 판사 답변 | 왼쪽에 판사 얼굴 아바타(40px 원, 옅은 버건디 바탕), 흰 말풍선(`SURFACE`, 테두리 `RULE`, 18px 모서리, 판사 쪽 아래 모서리만 6px) |
| 내 질문 | 오른쪽 버건디 말풍선 + 흰 글자 (다크 모드는 로즈 + 어두운 글자) — 주 버튼 색 변수를 그대로 사용 |
| 답변 준비 중 | 얼굴 아바타는 잠시 숨기고, 그 자리에 **전신 판사(54×72)가 판사봉을 두드리는 애니메이션** + 로딩 문구. 말풍선 테두리·배경 없음 |
| 답변 도착 | 로딩 메시지가 답변으로 덮어써지면서 애니메이션이 사라지고 얼굴 아바타 + 답변 말풍선으로 바뀜 |

- 채팅창 상자(배경·테두리·그림자)는 없앰. 높이는 화면의 56%(`56vh`, 최소 380px), 넘치면 스크롤.
- 메시지마다 복사 버튼만 남김(`buttons=["copy"]`). Gradio 기본 휴지통은 숨기고 대화 지우기는 `#clear-btn`으로 통일 (B가 상태까지 초기화하므로).
- 움직임 줄이기 설정: 로딩·빈 화면 애니메이션 모두 멈춤.

### 동작 원리 (로딩 애니메이션)

1. B의 `LOADING_TEXT`에 표식 `<span class="judge-busy"></span>`이 들어 있음 (합의 완료).
2. CSS가 이 `span` 자체를 54×72 크기의 스프라이트로 그려서 `steps(6, jump-none)`로 재생 → **표식이 곧 애니메이션 판사**.
3. 같은 답변 줄의 얼굴 아바타는 `:has(.judge-busy)`로 잠시 숨김.
4. 답변 첫 조각·오류·빈 답변 등 **모든 경우에** `on_ask()`가 로딩 메시지를 덮어쓰므로 표식이 사라지고, 판사는 얼굴 아바타로 돌아옴.

```python
# ui/chat_actions.py (B 담당, 합의 완료)
LOADING_TEXT = '<span class="judge-busy"></span>⏳ 답변을 찾는 중...'
```

### Gradio 내부 클래스 예외

Chatbot 안쪽(말풍선·아바타)에는 `elem_id`를 붙일 수 없어서, **`#chatbot` 안에서만** Gradio의 의미 있는 클래스 이름을 씁니다: `.bubble-wrap`, `.bot`, `.bot-row`, `.user`, `.avatar-container`, `button[aria-label="Clear"]`.
- 자동 생성 이름(`.svelte-xxxx`)은 여전히 금지.
- 변수로 해결되는 건 변수로: 말풍선 모서리 `--radius-md`, 그림자 `--shadow-drop`, 입력줄 안쪽 테두리 `--border-color-primary`·`--block-border-color`·`--input-*`를 해당 요소 안에서만 덮어씀.
- `requirements.txt`에 `gradio==6.30.0`이 고정되어 있음. **버전을 올릴 때는 이 클래스들이 그대로인지 화면으로 꼭 확인.**

### 스프라이트 준비 (새로 받은 이미지 기준)

원본: 2172×724, 가로 6컷, 투명 배경 → **그대로 쓸 수 있는 상태.** 다만 아래 정리가 필요합니다.

| 확인한 것 | 수치 | 처리 |
| --- | --- | --- |
| 배경 | 투명 ✅. 위쪽에 보이는 점들은 투명도 1/255짜리라 화면에선 안 보임 | 투명도 16 이하 픽셀은 0으로 지워서 깔끔하게 |
| 컷 간격 | 6등분(362px)이 아님. 실제 컷 폭 348~382px, 5·6번 컷은 서로 붙어 있음 | 6등분으로 자르지 않고, **캐릭터 덩어리 기준으로** 잘라냄 |
| 발 위치 | 발 바닥 높이는 모두 같음(y≈612) ✅. 가로 위치는 6등분 기준 최대 약 30px 차이 | 각 컷을 **발 중심 x**에 맞춰 같은 칸 가운데에 놓음 → 재생할 때 안 떨림 |
| 머리 높이 | 4·5번(내려치는 컷)이 다른 컷보다 약 15px 낮음 | 내려칠 때 몸을 숙이는 자연스러운 동작이라 그대로 둠 |
| 크기 | 캐릭터 한 컷 약 360×480 | 칸 하나를 3 : 4로 맞추고 2배 해상도 **144×192px**로 줄임 → 전체 864×192 WebP (수십 KB) ※ 이후 컷당 362×724(전체 2172×724)로 교체됨. 판사는 컷 안 y=170~584에 있어 `style.css`가 비율을 지킨 채 위아래 여백을 잘라 보여줌 |
